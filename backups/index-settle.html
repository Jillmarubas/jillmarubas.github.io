Super Agent Daily Briefing

n8n · AI Agent · Telegram
Published

Every morning a briefing is on my phone before I open a laptop. On a schedule, the agent reads the day's important emails, filters job alerts against saved criteria, checks tomorrow's calendar events, and writes a prioritised summary to Telegram.

It runs unattended with memory across runs, and each tool is a scoped call rather than a dump of the whole inbox — which is what keeps a briefing readable instead of a wall of text.

HOMEBODY Order CRM

n8n · Webhook · Gmail · Sheets
Published

Orders from the HOMEBODY store hit a webhook and are validated field by field before anything else happens. Valid orders get a confirmation email, and first-time buyers also get a welcome note after a short wait.

Anything malformed doesn't fail silently — it's formatted into a readable entry and appended to a Google Sheets error log, so a bad order is a row you can read rather than a support ticket you can't reproduce.

HOMEBODY Store

Web design · Netlify · Apps Script
Live

A furniture storefront with checkout logic that actually holds. WELCOME20 isn't text in an email — the site asks the server whether the code is valid before it shows a reduced total, and the server checks again when the order is placed. One customer can't use it twice.

The front end runs on a deliberately small motion system: one easing curve and three durations, hover and overlay only, no scroll-triggered effects. Every order it takes is what feeds the Order CRM above.

About

I build the plumbing between the tools you already pay for

Most of my work starts the same way. Someone is copying data from one screen into another, or opening a folder to check whether something arrived. It works until the day it doesn't, and then nobody can say what went wrong.

I replace that with a workflow that validates its own inputs, branches when the data is wrong, and writes down what it did. The logging matters as much as the automation — an order that fails should be a row you can read, not a mystery.

Lately most of that is agent work in n8n: scheduled runs with scoped tool access to Gmail, Calendar and Telegram, running on GPT-5 Mini and Gemini. I also design and build the front ends these systems sit behind, which means a project doesn't stall at the handoff between the automation and the interface.
