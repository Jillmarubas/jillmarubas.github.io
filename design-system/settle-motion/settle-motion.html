Principles

Four beliefs, each with a rule you can check

Arrive, then settle

Every entrance decelerates on settle. Exits use depart and run one step shorter.

Nothing in the reel lands at constant speed. Panels, cards and words come in fast and slow down into place, which is where the system gets its name.

Scroll is the playhead

Section reveals are scrubbed to scroll with a lerp of 0.12. Timed motion is only for feedback.

The headline words brighten as you scroll, and reverse when you scroll back. The viewer sets the speed, so there's no sequence to wait out.

One thing moves at a time

No more than 3 elements in flight. Stagger words by 60 ms and cards by 80 ms.

Groups cascade instead of arriving all at once, so the eye follows the order the reader should follow.

Mint means done

#ABFEC1 appears only when something has completed or is live. Never use it on hover.

In the reel, the only saturated color is the payment's success state. The faint green haze on black panels is the one ambient exception, kept under 14% opacity.

Tokens

Named once, used everywhere

Tokens are named by purpose, not value, so the numbers can change without renaming anything. Frame counts are rounded to the nearest whole frame.

Rules

The logo, and the pairs that settle arguments

✓Logo: allowed

  • Letters rise from a mask with a 40 ms stagger, on slow + settle.
  • Hold 250 ms, then glide to the nav at 42% scale.
  • Once per film, or once per session on the web.
  • The whole intro stays under 1.65 s.

✕Logo: never

  • Rotate, skew or stretch letters.
  • Blur the wordmark in. Blur is for content, not identity.
  • Color it mint, because mint means done.
  • Replay it on every page or section.

✓Open a menu in 200 ms on settle, and close it in 140 ms on depart.

✕Close it in the same 360 ms it took to open.

✓Stagger words by 60 ms, so a 9-word headline lands in about 900 ms.

✕Stagger by 150 ms, so the last word arrives after 1.5 s and the reader waits.

✓Blur in from 8 px, together with a 48 px rise.

✕Blur in from 30 px. It reads as a loading fault and drops frames.

✓Tie section reveals to scroll with a lerp of 0.12.

✕Start a 3 s timed sequence when a section comes into view.

✓Use snap for the success pill only.

✕Bounce every card entrance. When everything overshoots, nothing reads as special.

✓Use mint for completed, live or active data.

✕Use mint on hover, on idle buttons or for decoration.

Accessibility

Reduced motion keeps the meaning

When the viewer turns on reduced motion, travel, blur, scale and loops are removed. Everything else becomes a 200 ms fade or an instant change. Try it with the dock's Reduce switch.

Export

The whole system, in one block

CSS custom properties first, then the same values as a GSAP defaults object. For After Effects, use the influence values on the easing cards above.

/* Settle Motion · v1.0 */
:root {
  /* duration — ms · frames @30 / @60 */
  --dur-quick: 200ms;   /* 6f / 12f  — hover, press, menu */
  --dur-base: 360ms;    /* 11f / 22f — cards, morphs, counters */
  --dur-slow: 600ms;    /* 18f / 36f — panel rise, logo, chart */
  --dur-hero: 900ms;    /* 27f / 54f — film open only */
  --dur-loop: 12s;      /* ambient orbit */

  /* easing */
  --ease-settle: cubic-bezier(0.22, 1, 0.36, 1);   /* entrances */
  --ease-glide: cubic-bezier(0.65, 0, 0.35, 1);    /* in-view moves */
  --ease-depart: cubic-bezier(0.55, 0, 1, 0.45);   /* exits */
  --ease-snap: cubic-bezier(0.34, 1.56, 0.64, 1);  /* success only */

  /* choreography */
  --stagger-letter: 40ms;
  --stagger-word: 60ms;
  --stagger-card: 80ms;
  --rise-nudge: 8px;
  --rise-sm: 24px;
  --rise-card: 48px;
  --blur-in: 8px;
  --word-floor: 0.22;
  --panel-scale: 0.92;
  --press-scale: 0.96;
  --scroll-lerp: 0.12;

  /* palette */
  --ink: #0A0C0B;
  --paper: #FEFEFE;
  --mist: #F5F5F5;
  --graphite: #151515;
  --glow: #121B15;
  --floor: #525252;
  --mint: #ABFEC1;
}

@media (prefers-reduced-motion: reduce) {
  :root { --rise-nudge: 0px; --rise-sm: 0px; --rise-card: 0px; --blur-in: 0px; --panel-scale: 1; }
}

gsap.defaults({ duration: 0.36, ease: "power4.out" });

  dur: { quick: 0.2, base: 0.36, slow: 0.6, hero: 0.9, loop: 12 },
  stagger: { letter: 0.04, word: 0.06, card: 0.08 },
};
